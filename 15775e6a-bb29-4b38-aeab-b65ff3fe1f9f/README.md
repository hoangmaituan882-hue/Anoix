# 网页数据导出包使用说明

页面：株式会社トリガー | ANIMATION STUDIO TRIGGER Inc.
来源：https://www.st-trigger.co.jp/
导出时间：2026-08-30 12:29:32

包含从网页提取的完整数据，用于 AI 辅助页面还原和设计分析。

### 1. screenshot.png
- **用途：** 页面完整截图，用于视觉参考
- **特点：** 当前浏览器视口宽度下的完整纵向截图
- **优先级：** ⭐⭐⭐⭐⭐ 最重要的视觉参考

### 2. DESIGN.md
- **用途：** 面向 AI 的设计系统快照，包含机器可读令牌和页面样式说明
- **优先级：** ⭐⭐⭐⭐

### 3. index.html 和 style.css
- **用途：**
  - 快速预览页面效果
  - 理解 DOM 结构和样式关系
  - 验证数据的正确性
- **说明：**
  - 可以直接在浏览器中打开 index.html 查看效果
  - HTML 尽量保留原网页 class/id，以及 CSS 选择器实际用到的源网页属性
  - CSS 以可访问的原网页规则和字体规则为主，仅在缺少原网页规则时使用预览 reset
  - 不包含原网页脚本，不用于复现复杂业务交互

### 4. assets/
- **用途：** 页面图片、SVG、字体等资源
- **说明：** 资源采用平铺结构，HTML/CSS 中使用相对路径引用

## 🚀 快速还原指引

**目标：** 快速生成页面视觉效果，节省 token

**数据源优先级：**
1. ⭐⭐⭐⭐⭐ screenshot.png - 视觉参考
2. ⭐⭐⭐⭐ DESIGN.md - 设计系统快照
3. ⭐⭐ index.html - 离线 HTML
4. ⭐⭐ style.css - 样式文件

**操作步骤：**

1. **分析截图**
   - 识别页面整体布局（header、main、footer）
   - 识别主要视觉元素（导航、卡片、按钮等）
   - 识别颜色、字体、间距等设计风格

2. **读取设计系统快照**（从 DESIGN.md）
   - 颜色：背景色、文本色、边框色
   - 字体：字体家族、字号、行高、粗细
   - 间距：margin、padding、gap
   - 其他：圆角、阴影、线宽

3. **生成 DOM 结构**
   - 根据截图创建简化的 DOM 层级
   - 使用 index.html 理解文本和资源关系

4. **添加资源**
   - 图片和字体：使用 assets/ 中的资源

5. **微调样式**
   - 对比截图调整布局和样式
   - 确保视觉效果接近原页面
